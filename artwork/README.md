# Artwork from the Mak Rita app — reference only

A copy of every image in `mak-rita-code/assets/` (same folder structure), taken
2026-11-10. It is here so Claude and Steve can look at the app's style, Mak's
design and past illustrations.

- **Reference only.** Don't edit these files, and don't put them in a video as-is.
  Video art is generated per episode and approved at the gates.
- To use one as a model reference for a generation, pass it with `--image` to
  `pipeline/fal_run.py`. The approved model sheet in `character/mak-reference/`
  still comes first.
- `mak/` holds Mak in every mode and mood (`body/` = head and shoulders,
  `takeover/` = full body). `unused/mak/extra/*.prompt.md` are prompts used for
  earlier Mak art.
- The app repo is the source of truth. If its art changes, copy it again from
  `mak-rita-code/assets/`.
